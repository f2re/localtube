# 🔐 Security

LocalTube предназначен для одного локального пользователя **macOS, Linux или Windows** и не должен выставляться наружу через reverse proxy, port forwarding или изменение bind-address.

## Модель угроз

Сервис слушает только `127.0.0.1`. API требует случайный локальный токен и дополнительно проверяет `Host` и `Origin`. Статические файлы обслуживаются из фиксированного каталога с защитой от traversal. Входные URL разрешают только поддержанные YouTube endpoints. `yt-dlp`/FFmpeg запускаются через `Deno.Command` без shell-интерполяции пользовательского ввода.

Рабочему Deno-процессу не выдаётся blanket `-A`. Разрешения subprocess ограничены приватным runtime LocalTube и небольшим набором платформенных утилит: выбор файла/папки, открытие результата и завершение дочерних процессов. Файловый доступ остаётся широким, потому что пользователь вправе выбрать произвольную локальную папку назначения и `cookies.txt`; это сознательная граница модели безопасности.

## Платформенная изоляция

- macOS: пользовательский LaunchAgent и каталог `~/Library/Application Support/LocalTube`;
- Linux: каталог `${XDG_DATA_HOME:-~/.local/share}/localtube`, `systemd --user` при наличии, без `sudo`;
- Windows: `%LOCALAPPDATA%\LocalTube`, пользовательский PowerShell launcher, без admin/service-install.

Runtime не устанавливается глобально и не подменяет системные `deno`, `yt-dlp` или FFmpeg.

## Supply chain

Bootstrap скачивает Deno, yt-dlp и FFmpeg/FFprobe только по HTTPS. Где upstream предоставляет контрольную сумму, она проверяется до активации runtime. Источник и версии активных компонентов записываются в `runtime/manifest.json`.

Внешний fallback-runtime пользователя не должен изменяться скрытно. Собственный `yt-dlp` LocalTube допускает транзакционное самообновление; системная установка — нет.

Каждый release-архив имеет отдельный `.sha256`, внутри пакета есть `MANIFEST.sha256`. Для macOS Developer ID/notarization поддерживаются релизным процессом, но требуют Apple credentials владельца репозитория.

## Сообщение об уязвимости

Не публикуйте cookies, токены, личные пути и содержимое приватных файлов в публичном issue. Для воспроизводимого отчёта достаточно версии LocalTube, ОС, архитектуры, шага воспроизведения и обезличенного диагностического фрагмента.

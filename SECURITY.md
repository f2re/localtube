# 🔐 Security

LocalTube предназначен для одного локального пользователя macOS и не должен выставляться наружу через reverse proxy, SSH port forwarding или изменение bind-address.

## Модель угроз

Сервис слушает только `127.0.0.1`. API требует случайный токен, дополнительно проверяет `Host` и `Origin`; статические файлы обслуживаются из фиксированного каталога с защитой от traversal. Входные URL разрешают только поддержанные YouTube endpoints. `yt-dlp`/FFmpeg запускаются без shell-интерполяции.

Рабочему Deno-процессу не выдаётся blanket `-A`. Разрешения subprocess ограничены runtime-файлами LocalTube и несколькими системными утилитами macOS. Файловый доступ остаётся широким, потому что пользователь вправе выбрать произвольную локальную папку назначения и `cookies.txt`; это сознательная граница модели безопасности.

## Supply chain

Bootstrap скачивает Deno, yt-dlp и FFmpeg/FFprobe только по HTTPS и проверяет опубликованные upstream SHA-256. При невозможности загрузки допускается wrapper к уже установленному локальному инструменту; это явно фиксируется в `runtime/manifest.json`. Внешний yt-dlp никогда не обновляется через кнопку LocalTube.

Релизный ZIP имеет отдельный `.sha256`; внутри пакета есть `MANIFEST.sha256`. Developer ID / notarization поддерживаются релизным процессом, но требуют Apple credentials владельца репозитория.

## Сообщение об уязвимости

Не публикуйте секреты, cookies и личные пути в публичном issue. Для воспроизводимого отчёта достаточно версии LocalTube, macOS, архитектуры и обезличенного фрагмента `LocalTube-diagnostic-*.txt`.
